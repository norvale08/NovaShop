# Banki.shop — Интернет-магазин картин

Верстка макета интернет-магазина на Vue 2 (Options API). Тестовое задание.

**Демо:** https://nova-shop-two.vercel.app/

## Технологии

- Vue 2.7 (Options API)
- Webpack 5 + Babel
- CSS3 (адаптивная верстка, CSS-переменные)

## Функционал

- **Поиск** — фильтрация карточек по названию в реальном времени
- **Кнопка «Купить»** — состояния `Купить → Обрабатывается (2 сек) → В корзине`, каждое с своей иконкой
- **Сохранение состояния** — статус корзины хранится в `localStorage` и восстанавливается после перезагрузки
- **Модальное окно товара** — открывается по клику на название/изображение, содержит описание, цену и слайдер (2–4 изображения)

## Запуск проекта

Требуется Node.js 16+.

```bash
npm install       # установка зависимостей
npm run dev        # запуск дев-сервера — http://localhost:8080
npm run build      # сборка в папку dist/
```

## Адаптивность

Верстка адаптивна до 360px: сетка карточек перестраивается с 4 колонок (desktop) до 1 колонки (360px), шапка и модальное окно также адаптируются под мобильные экраны.

## Совместимость

Проверено в последних версиях Chrome, Firefox, Safari и Edge.
