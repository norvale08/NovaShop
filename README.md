# Banki.shop - Интернет-магазин

E-commerce приложение, разработанное с использованием Vue 2 (Options API) и TypeScript.

## Технологии

- Vue 2.7.14 (Options API)
- Webpack 5.89.0
- Babel
- CSS3 (Responsive design)

## Функционал

### 1. Поиск товаров
- Строка поиска в шапке сайта
- Фильтрация товаров по названию в реальном времени
- Скрытие товаров, не соответствующих запросу

### 2. Кнопка "Купить"
- Три состояния кнопки:
  - **Купить** - начальное состояние
  - **Обрабатывается** - показывается в течение 2 секунд после клика (с анимацией спиннера)
  - **В корзине** - финальное состояние после обработки
- Визуальное оформление состояний с иконками

### 3. Сохранение состояния
- Состояние корзины сохраняется в localStorage
- После перезагрузки страницы товары в корзине остаются отмеченными
- Автоматическое восстановление состояния при загрузке

### 4. Модальное окно товара
- Открывается при клике на название или изображение товара
- Содержит:
  - Краткое описание товара
  - Цену
  - Слайдер с 2-4 изображениями
  - Навигация стрелками и точками

## Установка и запуск

### Требования
- Node.js 16.x или выше
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:8080

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`

## Адаптивность

Приложение полностью адаптивно и корректно отображается на устройствах с шириной экрана от 360px:

- **360px - 480px**: Одна колонка товаров
- **480px - 768px**: Две колонки товаров
- **768px+**: Сетка с автоматическим количеством колонок

## Браузерная совместимость

Приложение корректно работает во всех современных браузерах:
- Chrome (последние 2 версии)
- Firefox (последние 2 версии)
- Safari (последние 2 версии)
- Edge (последние 2 версии)
